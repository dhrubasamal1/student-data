Delete Anonymous Users from Firebase Auth

Purging auth accounts from Google Firebase servers

How Firebase Auth Deletion Works:
Google Firebase client-side SDKs intentionally prevent browsers from deleting other students' Auth accounts for security. Your Firestore database records are already deleted by clicking "Delete Anonymous Users" in the Admin Panel. To delete the underlying anonymous Auth user accounts in Google Firebase servers, choose either method below:
Method 1: Firebase Console (1-Click) Recommended
  1. Open Firebase Console → Authentication → Users.
  2. Filter by Provider: select "Anonymous".
  3. Check the top checkbox to Select all users.
  4. Click Delete accounts.
Open Firebase Auth Users Console
